# Route change details

The public contract is generated by `go run ./cmd/docsgen`; do not hand-edit
`docs/api/generated/` or `internal/docsite/files/`.

## Add or change a route

1. Register its method and path in `internal/apidocs/table.go` and map it to its
   handler in `internal/docsgen/run.go`.
2. Add/update the request example and index row in `docs/api/examples/`.
3. Run `go run ./cmd/docsgen`; review the full diff, including schemas and
   `facts.json`.
4. Explain meaning, limits, partial failures, and retry behavior in
   `docs/api/manual/components/`. The generator cannot infer prose, interface
   dispatch behavior, or live Telegram/WordPress results.
5. Resolve every relevant item in `docs/api/generated/unresolved.md` from source
   evidence; do not invent a body, permission, response, or status.

## Remove a route

1. Remove it from both the API route table and generator route-to-handler map.
2. Remove its example and index row, then run the generator.
3. Search `docs/api/` for the old path and remove remaining claims that it is
   served. Do not retain a historical endpoint section.

## Checks and limits

Run `go run ./cmd/docsgen --check` and `go test ./internal/apidocs`. The latter
checks route coverage, links, anchors and examples against an in-memory gateway;
it does not prove live service behavior or prose correctness. A missing GET route
can be indistinguishable from a data 404 in the probe, so verify the route table
and generated docs as well. The `/docs` tree is embedded from
`internal/docsite/files`; regenerate and rebuild when it changes.
