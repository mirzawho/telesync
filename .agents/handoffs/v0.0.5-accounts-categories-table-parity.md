# Match My Accounts table to Categories

## A. Metadata

Status is `VERIFYING`; the user explicitly approved this handoff on
2026-11-14.

## B. Requirements

### Problem

The account table already uses the shared shadcn Table primitives, but its row
has a fixed `h-[68px]`, unlike the Categories table. The account table is also
not inside Categories' outer `rounded-xl border bg-card` wrapper, and the
Accounts page lacks the Categories table's bordered/card container.

### Desired behavior

Keep the five existing account columns, RTL order, account identity/avatar,
friendly server label, real status badge, formatted/empty last-connection date,
and all existing menu actions. Match Categories' outer table container and
default row sizing. Preserve shared table primitives, horizontal scrolling,
sticky opaque physical-left actions, and responsive table layout.

### Acceptance criteria

- [x] The accounts table uses the same `rounded-xl border bg-card` outer container as Categories.
- [x] Account row height/padding uses the same shared table defaults as Categories.
- [x] Shared headers, separators, hover, overflow, and sticky physical-left actions remain intact.
- [x] Existing account menu actions and status/permission logic are unchanged.
- [ ] Focused tests, full frontend typecheck, and production build pass.
- [x] Browser comparison is performed if the environment supports it.

### Out of scope

- Page title/subtitle, add button, login/details dialogs, authentication, status logic, APIs, backend, dependencies, commits, and pushes.
